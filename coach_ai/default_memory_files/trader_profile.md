# Trader Profile

Evidence-based assessment of trading behavior, updated incrementally via `update_fields` as new trade journal evidence accumulates. Each category below carries a `Confidence` field (0.0-1.0) and a `Last Updated` field alongside its content, so the assessment's certainty and recency are always visible. `Improvement Areas` is the exception: it is a running, evidence-based list rather than a fixed set of fields, and supports `append` with `history_limit`.
